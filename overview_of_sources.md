# Обзор источников

## Литературные источники

*Теоретические источники*
1. <https://www.allmultidisciplinaryjournal.com/uploads/archives/20250306175753_MGE-2025-2-017.1.pdf> - теоретическая база, современные тренды в области NRT-конвейеров, список технологий и подходов
2. <https://books.google.ru/books?hl=ru&lr=&id=6TczEAAAQBAJ&oi=fnd&pg=PT14&dq=real-time+payment+processing+pipeline&ots=yj7OmJRqpU&sig=hcNgKNlYZBIPRQHOKSBhyeraHMw&redir_esc=y#v=onepage&q&f=false> - фундаментальная информация
3. <https://books.google.ru/books?hl=ru&lr=&id=9yKJDwAAQBAJ&oi=fnd&pg=PR4&dq=payment+history+data+lake&ots=QN5WISfNyR&sig=3viDgbC5A0e7BPyGmMzJoJOM6Z8&redir_esc=y#v=onepage&q&f=false> - сохранение истории платежей
4. <https://hazelcast.com/use-cases/payment-processing/> - актуальность темы + исторические данные
5. <https://hevodata.com/learn/understanding-data-pipeline-architecture/> - теоретические данные + сравнительная таблица
6. <https://habr.com/ru/companies/otus/articles/757098/> - теоретические данные (базовые)
7. <https://bigdataschool.ru/blog/kafka-and-spark-streaming-for-financial-transactions/> - выбор инструментов, основные проблемы и пути их решения (+ метрики)
8. <https://datafinder.ru/products/arhitektura-konveyerov-dannyh-polnoe-rukovodstvo-po-vyboru-i-realizacii> - введение + артефакты


*Практические примеры*
1. <https://nuancesprog.ru/p/17175/> - пример архитектуры, которую можно адаптировать и оценить (инструменты: Kafka + ClickHouse, Materialized View)
2. <https://stripe.dev/blog/real-time-payment-analytics-stripe-to-aws-data-pipeline> - пример практической реализации в индустрии (инструменты: AWS-стэк, можно сравнить с инструментами из предыдущего шага; проблемы масштабирования, требования к пропускной способности)
3. <https://github.com/KashaniKasra/Real-time-Payment-Data-Pipeline-with-Kafka> - пример практического применения (в коде можно найти метрики)
